# Сравнительный анализ аналогов (Лабораторная работа №2)

Для проектирования системы «Warehouse Online» был проведён анализ существующих решений для управления складом. В качестве аналогов были выбраны три популярные системы: **1С:Склад**, **МойСклад** и **Excel (ручной учёт)**.

### Матрица сравнения

| Критерий | Warehouse Online (Наш проект) | 1С:Склад | МойСклад | Excel / Бумажный журнал |
| :--- | :---: | :---: | :---: | :---: |
| **Стоимость** | Бесплатно (Open Source) | Высокая (покупка лицензии) | Платная подписка | Бесплатно (но требует времени) |
| **Сложность внедрения** | Низкая (запуск за 5 минут) | Высокая (нужен специалист) | Средняя (настройка через облако) | Минимальная |
| **Доступ через браузер (Web)** | **Да** | Частично (через тонкий клиент) | Да (Облако) | Нет |
| **Учёт остатков** | Автоматический | Автоматический | Автоматический | Ручной (часто с ошибками) |
| **Разграничение прав (Роли)** | **Да** (Админ, Кладовщик) | Да | Да | Нет (все имеют доступ) |
| **Защита от минусовых остатков** | **Да** | Да | Да | Нет |
| **Отслеживание минимальных остатков** | **Да** (подсветка красным) | Да (настраиваемо) | Да | Нет |
| **Простота интерфейса** | Высокая (интуитивно понятно) | Низкая (сложный интерфейс) | Средняя | Высокая (но неудобно) |
| **Журнал операций (история)** | **Да** (кто и когда сделал) | Да | Да | Нет |

### Выводы по результатам анализа

1. **1С:Склад** — мощная система, но она избыточна для малого бизнеса или небольшого склада, требует сложной настройки и стоит дорого. Наш проект решает эту проблему за счёт лёгкости и бесплатности.
2. **МойСклад** — отличный облачный сервис, но он требует ежемесячной оплаты. Наш проект даёт базовый функционал бесплатно.
3. **Excel** — самый дешёвый вариант, но он не даёт автоматизации, легко допустить ошибку и нельзя разграничить права доступа (любой, кто открыл файл, может стереть всё).

**Заключение:** Разрабатываемая система **Warehouse Online** занимает идеальную нишу — она бесплатная, простая в установке, работает прямо в браузере, защищает от ошибок (минусовых остатков) и имеет понятный интерфейс, в отличие от тяжёлых корпоративных систем.
