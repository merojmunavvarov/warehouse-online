# Warehouse Online — Система управления складом

## О проекте

**Warehouse Online** — современная веб-система для управления складскими запасами, учёта товаров, контроля поставок и отслеживания остатков в режиме реального времени.

Платформа позволяет кладовщикам и администраторам вести номенклатуру товаров, оформлять приходные и расходные операции, управлять справочниками (категории, поставщики), а также получать актуальную статистику по стоимости склада и товарам, требующим пополнения.

## Цель и задачи проекта

**Основная цель:** разработка единой веб-системы для автоматизации процессов учёта товаров на складе, контроля поставок и управления остатками.

### Основные задачи

1. Разработка системы регистрации и авторизации пользователей с разграничением прав доступа (Администратор, Кладовщик).
2. Создание функционала для ведения справочника товаров (номенклатуры).
3. Управление категориями товаров и справочником поставщиков.
4. Реализация системы оформления приходных документов (поступление товара от поставщика).
5. Реализация системы оформления расходных документов (продажа, списание, брак).
6. Автоматический пересчёт остатков на складе после каждой операции.
7. Контроль минимальных остатков (выявление товаров, требующих закупки).
8. Разработка дашборда с ключевыми показателями (стоимость склада, количество позиций).
9. Формирование отчётов по текущим остаткам.
10. Организация хранения и обработки данных в реляционной базе данных.

## Участники системы и их роли

Система предусматривает две основные категории пользователей.

### 1. Администратор (Administrator)

*   Полный доступ ко всем разделам системы.
*   Управление пользователями (создание и удаление аккаунтов, назначение ролей).
*   Управление справочниками (категории, поставщики).
*   Просмотр всех операций (приход/расход).
*   Контроль работы системы в целом.

### 2. Кладовщик (Storekeeper)

*   Авторизация в системе.
*   Просмотр дашборда и отчётов.
*   Добавление и редактирование товаров.
*   Оформление приходных и расходных операций.
*   Просмотр истории движения товаров.

*   **Среда разработки:** Windows, XAMPP, Visual Studio Code

Принцип работы системы
Пользователь открывает систему и авторизуется.

Для начала работы кладовщик создаёт категории товаров.

Добавляет поставщиков, у которых планируется закупка.

Создаёт карточки товаров, указывая цену и минимальный остаток.

При поступлении товара оформляет документ «Приход».

При продаже или списании товара оформляет документ «Расход».

Система автоматически пересчитывает остатки и стоимость склада.

Если остаток товара падает ниже минимального, система подсвечивает его на дашборде.

В разделе «Отчёты» можно посмотреть актуальные остатки и их общую стоимость.

Администратор может создавать новых сотрудников (кладовщиков).
