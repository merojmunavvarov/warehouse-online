# Развертывание системы (Deployment)

В данном разделе описаны файлы, отвечающие за развертывание веб-приложения «Warehouse Online».

1. **07-deployment.puml** — исходный код диаграммы развертывания (PlantUML).
2. **06-er-diagram.puml** — исходный код ER-диаграммы базы данных.

Для локального запуска проекта используется веб-сервер Apache и СУБД MySQL (в составе пакета XAMPP). Подробная пошаговая инструкция по установке находится в файле `16-deploy.md`.
