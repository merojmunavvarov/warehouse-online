# Логическая модель базы данных (Лабораторная работа №6)

База данных «Warehouse Online» состоит из 6 взаимосвязанных таблиц. Модель приведена к Третьей нормальной форме (3NF).

## Описание таблиц:
1. **users** — учетные записи (админы и кладовщики). Пароли хешируются.
2. **categories** — справочник категорий товаров.
3. **suppliers** — справочник поставщиков.
4. **products** — номенклатура товаров (артикул, цена, минимальный остаток).
5. **stock_in** — журнал приходных операций.
6. **stock_out** — журнал расходных операций.

## Связи (Relationships):
*   `categories` 1:N `products` (При удалении категории `category_id` становится NULL).
*   `suppliers` 1:N `stock_in`
*   `products` 1:N `stock_in`
*   `products` 1:N `stock_out`
*   `users` 1:N `stock_in`
*   `users` 1:N `stock_out`

## Ограничения (Constraints):
*   Поля `email` (в users) и `sku` (в products) имеют ограничение `UNIQUE` (уникальность).с
